# Danceblox Api Monorepo
### TikTok Live -> Roblox Game Pipeline

### Project capable of integrating tiktok live comments directly to render skins in a custom made roblox game in Luau / Rojo 
#### Tech Stack
- Python Fastapi for core infraestructure
- Kafka for async api communication
- Rojo and Luau for building the game
- Deployed both in Docker and in Roblox Studio
